MCP testing

Enter a natural language request for Groq. The app discovers ticket tools from the MCP server and runs the tool Groq selects. The MCP server uses the same REST API and database shown in the Direct API panel.

Enter an instruction to see which MCP tool Groq selects and what it returns.
Try it: “Show ticket ID 1” or “Set ticket 1 to closed.” Calls and results appear above.
How to compare: Direct API mode sends your chosen HTTP method and endpoint to FastAPI. MCP mode sends your natural-language request to Groq, discovers MCP tools, and runs the selected tool. Both ultimately read or change the same SQLite ticket rows.
